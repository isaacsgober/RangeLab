## Problems Encountered

- dnsmasq failed to start after boot; DNS resolution unavailable lab-wide, causing vCenter VAMI errors.
- vCenter could not add [[esxi01]] as a managed host — certificate push failed, then a 503 on retry. **Unresolved.**
- The Rocky online repositories were unreachable: VMnet10 has no route off the subnet; this is an isolated lab.
- `nano`, `nslookup`, and other common tools are absent from a Minimal Install and could not be added until a package source existed.
- The clone of [[ansible01]] inherited its hostname, IP, SSH host keys, machine-id, login history, and admin account name.
- [[managed01]] was initially unreachable by name — DNS records still referenced the earlier planned hostname `rocky01`.

---

## Solutions

- Replaced `bind-interfaces` with `bind-dynamic` in `/etc/dnsmasq.conf`, resolving a startup race where dnsmasq started before `ens160` was up.
- vCenter host attachment deferred; VM creation proceeded via the ESXi host web UI, which does not depend on vCenter.
- Mounted the DVD ISO at `/mnt/rocky-iso` and defined `local-baseos` and `local-appstream` repositories pointing at it; disabled the unreachable online repos.
- Used `getent hosts` in place of `nslookup` for resolution testing, and `vi` in place of `nano`.
- Regenerated SSH host keys with `ssh-keygen -A`, reset machine-id, and renamed the admin account with `usermod`.
- Updated the dnsmasq records to `managed01` and restarted the service.

## Concepts Learned

- Git's three states — working directory, staging area, and commit — and how `add`, `commit`, `restore --staged`, and `rm` move files between them.
- `.gitignore` only applies to untracked files; once a file is tracked, ignore rules no longer protect it.
- Line endings (LF vs CRLF) are real bytes that git tracks, and `core.autocrlf` controls conversion.
- Linux configuration lives in plain text files in known locations — `/etc`, and `.d` directories holding per-source fragments.
- `dnf` resolves dependencies from repositories defined in `/etc/yum.repos.d/`; a repository can be a local path as easily as a URL.
- Cloning a VM copies everything on disk, including identity that should be unique. Production environments generalize an image before templating it.
- A vSwitch port group is a distinct layer from the hypervisor host's underlying network.
- vCenter is a management appliance, not a compute platform — VMs run on the ESXi host regardless of which interface creates them.
