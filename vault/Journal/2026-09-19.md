## Concepts Learned

- **`openssl s_client | openssl x509`.** `s_client` connects over TLS and prints the handshake,
  with the server's certificate inside it as base64 between `BEGIN` and `END CERTIFICATE`.
  `echo |` gives it input that ends at once, so it exits instead of waiting. `2>/dev/null`
  discards its status messages (stream 2), including the verify error from not trusting VMCA.
  `x509` decodes the certificate; `-noout` skips reprinting it, and `-subject`, `-issuer`, and
  `-ext subjectAltName` choose the fields.
- **Certificate names.** A CA (Certificate Authority) signs certificates; vCenter runs its own,
  VMCA. In a Distinguished Name, `CN` is Common Name, `DC` a Domain Component, `O` Organization,
  and `OU` Organizational Unit. On VMCA's issuer, `O` names the vCenter that signed.
- **`never` is overridden by any other tag on the task, including tags inherited from its role.**
  `tags: common` on the role made `--tags common` select the update task.
- **`/etc/profile.d/` applies at login.** A shell started before the file existed keeps its old
  `PATH`, and a non-login `ssh host 'command'` never reads it.
- **Minimal Install ships `openssl-libs`, not `openssl`.** The library everything links against
  and the command-line tool are separate packages.
- **The Rocky installer ejects its media on reboot**, which clears **Connected** on a VMware
  virtual drive. On EFI, the installer also adds a boot entry ahead of the CD drive.
- **A powered-off VM's clock is set from its host at power-on.** Only suspending freezes a guest
  clock.
- **Kernel messages print to the system console,** not to SSH sessions. They appeared on the
  console while journald restarted, and at boot for the NVMe and device-mapper notices.
- **OpenSSH connection sharing.** A master connection (`ControlMaster`) holds one authenticated
  session that other `ssh` commands reuse through a socket. Git for Windows' `ssh` cannot pass
  file descriptors, so ordinary sharing fails there; `-O proxy` relays the session through the
  master instead.
