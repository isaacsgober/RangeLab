- `/sbin/generate-certificates` fixed the SAN but produced a *self-signed* certificate. vCenter tried to replace it — `Untrusted certificate found ... Pushing new certificate...` — and the push itself failed, because delivering a trusted certificate needs a trusted connection.

## Concepts Learned

- ESXi runs VMkernel, VMware's own kernel, not Linux. Its shell is BusyBox, its services restart through `/etc/init.d`, and its software ships as VIBs in an image. The VCSA runs Photon OS, a real Linux distribution with systemd (wrapped by `service-control`) and RPM packages.
- `hostd` manages the ESXi host; `vpxa` is vCenter's agent running on it. The DCUI is the host's console menu; the ESXi Shell (TSM) is a separate service that can be switched on and off.
- A TLS certificate proves identity as well as encrypting traffic. Modern clients check the **SAN**, not the CN. `openssl x509 -text` shows both, and `-issuer` tells a CA-issued certificate from a self-signed one.
- VMCA binds a host certificate to whatever identifier was used to add the host. A certificate authority's automatic replacement can deadlock: delivering a trusted certificate needs a trusted connection.
- A Trusted Root store only accepts CA certificates, not leaf certificates.
- Shell tools: `less` (`G`, `/`, `?`, `n`, `q`); `tail -f` stopped with Ctrl+C; `printf` and `tee -a`; `grep -A`, `-i`, `-E`, and `--line-buffered`; `cat > file` finished with Ctrl+D; `PATH`. Chaining `grep`s drops multi-line log context, because each stage only sees what the last one kept.
- `vmkping -I vmk0 <target> -d -s 1472` tests for an MTU mismatch: `-d` forbids fragmentation, and 1472 bytes plus 28 bytes of IP/ICMP header fill a 1500-byte frame exactly.
- A server bound to `0.0.0.0` listens on every interface. A firewall that `DROP`s makes a connection hang; one that `REJECT`s makes it fail immediately.
- Load average only means something against core count: 13.46 on 2 cores is heavy oversubscription. In `free -h`, the `available` column is what matters; a low `free` number is just cache.
