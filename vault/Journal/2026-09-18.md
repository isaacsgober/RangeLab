- GitHub's stock Pylint workflow failed its first run on `main`.
- After the cold boot, SSH to esxi01 was refused.

---

## Solutions

- The `getent` result was `nss-myhostname` answering for the machine's own name after DNS returned
  NODATA for AAAA; `getent ahostsv4` returns the right address. No fix needed.
- A type after `dig -x` replaces PTR, and reverse names carry only PTR records. Plain `dig -x`
  was correct all along.
- `ssh-keygen -R <address>` cleared the pre-rebuild host keys.
- Pushed from VS Code's integrated terminal, which supplies GitHub credentials.
- Removed `tags: always` from the four `common` tasks.
- Set NTP with `esxcli system ntp set --server=infra01.rangelab.internal --enabled=true`.
- Removed the workflow by resetting `main` to the PR #9 merge and pushing with
  `--force-with-lease`.
- SSH enabled in the DCUI does not survive a reboot. Kept that way deliberately, as ESXi's
  hardening default; esxi01 is checked on port 443 instead.

## Concepts Learned

- **`--limit` narrows execution, not the inventory.** `groups` and `hostvars` still hold every host,
  so a run limited to the DNS server can generate records for a node nothing ran on.
- **Tags on a role apply to every task inside it**, and `always` overrides any tag selection.
- **How vCenter adds a host.** It trusts the host's certificate by accepted thumbprint, then VMCA
  issues a replacement carrying whatever identifier was used for the add. VMCA backdates
  certificates by 24 hours to tolerate clock skew.
- **The SSO domain is a directory namespace, not a DNS name.** It must never match an Active
  Directory domain and cannot be renamed later.
- **Appliances are managed through their own interfaces.** VCSA runs Photon OS, but package,
  time, and network changes belong to its installer, VAMI, and API, not to Ansible roles.
- **dnsmasq answers NXDOMAIN for non-PTR types on reverse names.** Strictly wrong, harmless in
  practice, since nothing asks for addresses of `in-addr.arpa` names.
- **Stopped vCenter services are normal when their startup type is Manual.** Only a stopped
  Automatic service is a problem.
- **An autostart shutdown delay is a grace period.** A guest still running when it expires is
  powered off.
- **SSH keys `known_hosts` entries by the name as typed.** An FQDN and an IP for the same host are
  separate entries.
- **`git reset --hard` moves a branch label; `--force-with-lease` replaces a remote branch only if
  it hasn't changed since the last fetch.** Discarded commits stay in `reflog` for 90 days.
- **Linear closes issues from PR text**, using a closing keyword followed by the issue ID; its
  team key, `ISA`, comes from the team name.
- **The Windows host resolves lab names** because its VMnet10 adapter uses `10.10.10.2` for DNS.
- **The Stratum column in `chronyc sources` is the source's stratum**, not the local node's. A
  client showing `^* infra01 … 3` is itself at stratum 4.
