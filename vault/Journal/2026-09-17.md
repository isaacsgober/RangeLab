## Concepts Learned

- **Source NAT.** Private addresses are not routable outside, so nothing upstream has a route back
  to `10.10.10.0/24`. As a packet leaves `eth0`, vyos01 rewrites its source address — and usually
  its source port — to the router's own WAN address, and records the mapping in a
  connection-tracking table. The reply comes back to that address, the router looks the flow up,
  rewrites the destination, and forwards it in. `masquerade` means "use whatever address the
  outgoing interface currently holds". Because the table only holds flows that started inside,
  nothing outside can open a connection inward without an explicit rule.
- **Two independent resolvers on a router.** `system name-server` serves the router's own
  processes; `service dns forwarding` is a PowerDNS Recursor serving other machines. Nothing
  connects them, so `ping vyos.net` from the router proves nothing about what clients get. A
  recursor also validates DNSSEC, which turns one client query into several upstream round trips —
  which is what exposed a slow upstream.
- **`SERVFAIL` vs `NXDOMAIN`.** "I could not get an answer" versus "that name does not exist".
- **Why `-i`.** Plain `sudo -u ansible` changes the user ID but keeps the current directory, and
  home directories on Rocky are mode 700. Run from `/home/labadmin`, ansible-lint starts as
  `ansible`, stats `.` during import, and dies with
  `PermissionError: [Errno 13] Permission denied: '.'` — which looks like a broken install and is
  not one. `-i` simulates a login: it starts the account's login shell in its own home with its own
  environment, which is also how the `ansible` account will actually run playbooks. Because `-i`
  rebuilds `PATH`, keep using full paths for anything in a virtual environment.
- **Branches are labels.** A commit is an immutable snapshot; a branch is a movable pointer at one.
  `cherry-pick` copies a change onto a new parent, which necessarily produces a new commit ID;
  `branch -f` moves a label; `reflog` keeps the old positions for 90 days. Rewriting is free while
  nothing is pushed.
- **Linear closes its own issues.** GitHub's closing keywords only work on GitHub issues; Linear's
  integration watches merged PRs for its own identifiers in the title, body, or branch name.
